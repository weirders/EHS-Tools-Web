How to Use

  • Hierarchy: one line per node; use TAB for the next why-level.
  • M-tags: add flexible tags like #Method, #Machine. Appear as coloured pills.
  • Node colour: @red, @yellow etc. to mark status.
  • Actions: end a node line with \ followed by the action text, e.g. \Investigate root cause.
  • Legend: root line like @red Action required becomes a legend item (not a node).
  • Click node in tree: jumps to the corresponding line in the editor.
  • Direction: choose LR, TB, BT or RL.
  • Fishbone: only tagged nodes are shown. Untagged are dropped.
  • Undo: Ctrl+Z undo, Ctrl+Shift+Z / Ctrl+Y redo (up to 50 steps).
  • Indent: Tab / Shift+Tab indent or outdent the current line — or every line of a multi-line selection.
  • Paste: always inserted as plain text — spaces, bullets and numbered lists are converted to TAB indentation automatically.
